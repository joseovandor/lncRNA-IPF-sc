# data/

This directory is not tracked by git (raw matrices, annotations and results are large and/or
derived from controlled data). Expected layout before running the pipeline:

```
data/
├── VUILD53/ VUILD63/ VUILD64/ VUHD67/
│   ├── cellranger/                  # matrix.mtx.gz, features.tsv.gz, barcodes.tsv.gz
│   └── TAR/
│       ├── TAR_feature_bc_matrix/   # TAR-scRNA-seq feature-barcode matrix
│       └── TAR_reads.bed.gz         # per-sample TAR regions
├── annotations/
│   ├── gencode.v47.annotation.gtf.gz
│   └── external/                    # LncBook.gtf.gz, NONCODE.bed.gz, LNCipedia.bed, FANTOM_lncRNA.bed
└── reference/
    └── Homo_sapiens.GRCh38.dna.primary_assembly.fa
```

Generated by the scripts: `TAR_QC_summary.csv`, `TAR_cell_QC.csv`, `TAR_catalog/`,
`known_IPF_lncRNA/`, `single_cell_RNA_Habermann/`, `single_cell_TAR/`, `plots/`.
